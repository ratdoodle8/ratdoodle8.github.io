CHESS GAME FILES

Open index.html to play.

PIECE ART
Replace any PNG inside images/pieces with your own artwork.
Keep the same filename and use a 3:4 vertical image (150 x 200 pixels recommended).
Rooks, knights, and bishops have separate -left and -right files for both colors.
Kings and queens use one file per color. All pawns share one pawn file per color.

BACKGROUND ART
Replace images/background.png with your own image using the same filename.

CHECKERBOARD COLORS
Open index.html and find this section near the top:

--light-square: #e8eef0;
--dark-square: #7d9299;

Replace either hex code with the color you want.

GAME MODES
Choose Two Players or Vs. Random Computer from the menu above the board.

BOARD SQUARES
All 64 squares are locked to equal dimensions. Piece images and game states cannot resize individual squares.
